# Advent of Code

My [Advent of Code](https://adventofcode.com) solutions in TypeScript, one folder per year.

| Year | Folder |
|------|--------|
| 2021 | [`2021/`](2021) |
| 2022 | [`2022/`](2022) |

Each year is a standalone [aocrunner](https://github.com/caderek/aocrunner) project — `cd` into the year and install/run from there.

Merged from the former `aoc2021` and `aoc2022` repos with full history.
